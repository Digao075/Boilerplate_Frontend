# React + Vite + Chakra UI Boilerplate

Um starter kit moderno e opinativo para iniciar projetos frontend rapidamente.

## Tecnologias

- **Framework:** React 18+
- **Build Tool:** Vite
- **UI Library:** Chakra UI
- **Roteamento:** React Router DOM
- **Requisições HTTP:** Axios

## Como Começar

1.  **Clone o repositório:**

    ```bash
    git clone [URL_DO_SEU_BOILERPLATE] nome-do-novo-projeto
    ```

2.  **Navegue para a pasta do projeto:**

    ```bash
    cd nome-do-novo-projeto
    ```

3.  **Instale as dependências:**

    ```bash
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

O servidor estará rodando em `http://localhost:5173`.

## Estrutura de Pastas

- `src/components`: Para componentes reutilizáveis (Navbar, Botões, etc.).
- `src/pages`: Para componentes que representam páginas inteiras.
- `src/Layout.jsx`: Componente de layout principal que inclui a Navbar.
- `src/App.jsx`: Onde as rotas da aplicação são definidas.
- `src/main.jsx`: O ponto de entrada da aplicação, onde os Provedores são configurados.
